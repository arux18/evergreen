I need to create a FE ticket for the primary font change from Heebo to Gothic A1. Here are the details:

We are replacing Heebo with Gothic A1 throughout all our work; this will apply to the whole app, welcome pages, landing pages, specialized components, Gen UI / Open UI components, registration pages, etc. We should not be using Heebo anywhere anymore once this change is implemented.

It's a minor but impactful difference... Gothic A1 renders a little larger than Heebo at the same size, and the weight is a little thinner, making it easier on the eyes to read. The thinner weight of Gothic A1 also makes it appear a little more high-end, instead of chunky. Additionally, we wanted the number characters in our primary font to be monospaced with each other; we had this with Heebo and this continues with the Gothic A1 number characters.
