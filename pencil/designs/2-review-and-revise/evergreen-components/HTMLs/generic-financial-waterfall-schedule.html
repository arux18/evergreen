Financial waterfall schedulegeneric component · the analysis as numbers: line items building to bottom lines
Anatomy — designed once, inherited by every instance
① kicker — what is being scheduled · period · context tag
② hero — the bottom-line verdict, stated as a decision-relevant sentence
③ column headers — single | multi-period (years) | comparison (options) forms
④ line-item rows — signed amounts, indented sub-items, negatives in parentheses
⑤ subtotal rows — weighted by a stronger rule, never bold-only
⑥ bottom line(s) — one per column; comparison form adds a Δ row
⑦ disclosure footer — assumptions, always present
Data contract: { form: single|multi_period|comparison, columns[], rows:[{label,amounts[],type:item|sub|subtotal}], bottom_lines[], delta_row?, disclosures[] } — totals computed by the component, never the LLM
