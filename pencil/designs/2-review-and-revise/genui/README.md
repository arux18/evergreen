# genui/ — GenUI Factory Design Captures (in review)

`.pen` files in this folder are **outputs of the GenUI Component Factory pipeline**
(`specialized-components/genui-factory/`) — state catalogs captured from Bill's HTML
prototypes by dispatched pipeline agents, named `GC-NNN-<slug>.pen`.

- Files arrive here via pipeline pushes during the oracle stage.
- At oracle lock they promote mechanically to `../../4-approved/genui/`.
- Colors are bound to Hemlock T2/T3 semantic tokens only (see the
  semantic-color-tokens skill); Heebo type; one frame per contract state.
