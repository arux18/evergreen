# Content & Voice

## Tone: Calm, Precise, Empowering
- **Calm:** never urgent, alarming, or judgmental
- **Precise:** specific numbers, dates, sources
- **Empowering:** frame insights as tools, not directives

Never: panicky, vague, patronizing, salesy.

## Patterns

| Type | Pattern | Example |
|---|---|---|
| Insight | Observation + comparison + driver | "Your dining expenses increased 23% this month vs. your 3-month average. This is primarily driven by 4 transactions over $75." |
| Recommendation | Action + quantified impact + reasoning | "Increasing your 401(k) from 6% to 10% could save $3,200 in taxes this year and add ~$180K to retirement by age 65." |
| Error | What happened + reassurance + action | "We couldn't connect to Chase right now. Your data is safe — this is usually temporary. Try again, or we'll auto-retry in 15 minutes." |

## Confidence language
| Confidence | Language |
|---|---|
| High (>80%) | "Based on 24 months of data…" |
| Medium (50–80%) | "Based on available data, it appears…" |
| Low (<50%) | "With limited data, we estimate…" |
| Projection | "Based on historical patterns, this may…" |

Never use: "will", "definitely", "guaranteed", "you need to".

## Button labels

| Role | Good | Bad |
|---|---|---|
| Primary | "View Details", "Apply Recommendation", "Connect Account", "Set Up Auto Transfer" | "Click here", "Do it", "Add", "Start" |
| Destructive | "Remove Account", "Dismiss", "Cancel Transfer" | "Delete", "Delete forever", "Stop" |
| Safe/cancel | "Keep Account Connected", "Not Now", "Go Back" | "Cancel", "Dismiss" |

The safe option describes the safe outcome, not just negates the action.

## Numbers in text
- Always: exact values ($4,281.37), baseline ("vs. 3-month average"), period ("Mar 1 – Apr 9"), source ("across 12 transactions")
- Never: "about $4,300", "around 20%", "a few transactions", "recently"
- Use `~` only for projections, never for actual data

## Empty state copy
| State | Example |
|---|---|
| New user, no data | "Welcome! Connect your first account to start tracking your finances." |
| No results for filter | "No transactions found for this period. Try adjusting the date range." |
| Goal not started | "Ready to start your Emergency Fund? Even $25/month makes a difference over time." |
| Zero balance | "You just opened this account. Set up automatic transfers to start building." |

## Disclaimer (required on all AI projections / recommendations)
> "This is not financial advice. Projections are estimates based on historical data and may not reflect future results."

Use `GenUI/Financial Disclaimer`. Never omit. Never soften.
