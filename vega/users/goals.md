# User Goals → Component Map

| Goal | Triggers | Primary Components |
|---|---|---|
| "Am I okay?" | App open, daily check | `KPI Card/Value Up·Down·Neutral`, `KPI Sparkline Card`, `Gain First Summary` |
| "Where did my money go?" | Transaction review | `Transaction Item`, `Budget Category Row`, `Filter Row`, Donut/Bar Charts |
| "Am I on track?" | Goal/budget check | `Progress Bar Card`, `Monte Carlo Chart`, `AI Confidence` |
| "What should I do?" | Action/optimization ask | `AI Recommendation Card`, `AI Insight Card`, `Suggested Prompts` |
| "Show me something I didn't know" | Proactive surfacing | `AI Insight Card` (proactive), `Inline Data Mention`, `Calm Notification` |
| "Help me plan" | Scenario modeling | `Monte Carlo Chart`, `Comparison Metric`, `Waterfall Chart`, `Candlestick Chart` |
| "Prove it to me" | Verification/audit | `Financial Disclaimer`, `Data Freshness Badge`, `AI Confidence`, `Holdings Table` |
